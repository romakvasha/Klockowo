# Записані голосом фрази (заміна синтезу)

Якщо синтезований польський голос вимовляє якесь слово чи число неправильно, його можна замінити записом:

1. Запишіть фразу (mp3, тихо, без шуму) і покладіть у цю теку під ім'ям `<slug>.mp3`.
2. Додайте `slug` у масив у `manifest.json`, наприклад `["trzynascie", "piecdziesiat"]`.

`slug` — текст фрази латиницею: малі літери, без діакритики, розділювач «-», без розділових знаків.
`trzynaście` → `trzynascie`, `Brawo! Pięć jabłek.` → `brawo-piec-jablek`.
Готовий slug кожної фрази показано сірим на сторінці `/#/dev/speech` — копіюйте звідти.

Без запису в `manifest.json` файл не використовується. Якщо mp3 не зіграє, додаток озвучить фразу синтезом.
