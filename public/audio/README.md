# Записаний голос

Тут лежать записи голосу для гри: тека на мову (`pl/`, згодом `uk/`, `en/`), у ній по одному mp3 на речення і `manifest.json`:

```json
{ "voice": "<voice_id>", "model": "eleven_v4", "complete": false, "clips": { "<ключ речення>": "<файл без .mp3>" } }
```

- Ключ речення — текст малими літерами, без крапки чи знака оклику в кінці (`Siedem.` і `siedem` — один запис).
- Висловлювання звучить записом, лише якщо записано **кожне** його речення; інакше все висловлювання каже браузерний голос (два голоси в одній фразі не змішуються).
- `complete: true` — записано все, що гра каже цією мовою: тоді екран «Brak głosu» не потрібен.

Файли не редагуйте вручну — їх створює `node tools/voice/generate.mjs` (інструкція: `docs/VOICE.md`).
