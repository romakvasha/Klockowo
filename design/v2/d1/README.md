# D1 — дизайн усіх екранів (знімок полотна Claude Design)

Головна версія — полотно Claude Design: https://claude.ai/artifact/RTQ56FUUG3bX9Z3SqcYQbM (приватне; правки власника — там).
Тут — знімок його джерел на 2026-10-29 (D1b: схвалено власником, 36 дошок), щоб D2b/D3 мали з чого брати розміри й стилі.

- `kl.css` — спільна система: токени кольорів, цеглинки (`.bk`, стани плиток `.tw.sel/.ok/.retry`), HUD, хмаринка, сітка гри `.g-game` (HUD · провідник · дошка · лоток) для ПК (`.pc`) і телефона (`.ph`).
- `*.dc.html` — по дошці на екран: ліворуч ПК 1280×720, праворуч телефон 390×844 (той самий шаблон, сітка перебудовується класом `.pc` / `.ph`); під ПК — що говорить голос і що є заглушкою.
- `canvas.json` — розкладка дошок на полотні.
- Картинки на полотні: `img/` — стиснуті копії `design/v2/photos` і `design/v2/cut`; `art/`, `i/` — копії `src/assets` (іконки перефарбовані в білий `w-` і темний `k-`). У знімок не скопійовано.
