# Сюди — експорт із Claude Design

Покладіть у цю папку все, що дав Claude Design:
- експортовані файли (HTML, CSS, JS/JSX, SVG, PNG); zip-архів — розпакуйте сюди;
- за бажанням — скріншоти ключових екранів (Start, мапа, ігровий екран, персонажі), якщо в експорті їх немає.

Структура довільна: на етапі M0 Claude Code перегляне все і складе `design/INDEX.md` — короткий зміст, яким користуватимуться всі наступні сесії.

Якщо Claude Design дав посилання або команду для передачі дизайну в Claude Code, вставте їх у перше повідомлення разом зі стартовим промптом.
