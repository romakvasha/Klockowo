# Реалістичний голос (ElevenLabs) — інструкція для власника

Голос генеруємо **один раз на вашому комп'ютері** і зберігаємо як mp3-файли в проєкті. Сайт лише програє готові файли: ключ ElevenLabs і запити до сервісу на сайт не потрапляють, офлайн-режим працює, у Chrome звучить і українська.

## 1. Акаунт і тариф

1. Зареєструйтеся на https://elevenlabs.io.
2. Для **проби** вистачить безкоштовного тарифу (10 000 кредитів на місяць; 1 символ ≈ 1 кредит). Одна проба — приблизно 600 символів на мову для кожного голосу.
3. Для **всієї гри** (≈ 550 шматків на мову, разом ≈ 20 000 символів на три мови, плюс запас на перегенерацію) вистачить одного місяця найдешевшого платного тарифу (Starter). Якщо хочете **клон власного голосу** — він є з Starter (Instant Voice Cloning). Ціни змінюються — перевірте на https://elevenlabs.io/pricing.

## 2. Ключ API

1. На сайті ElevenLabs: аватар → **API Keys** (або Developers → API Keys) → **Create API Key**.
2. Дозволи: обов'язковий лише **Text to Speech**. Дозвіл на голоси (Voices → Read) потрібен тільки для автоматичного списку голосів; якщо його не видно — не страшно (див. нижче). Якщо меню дозволів незрозуміле, можна взагалі не обмежувати ключ — головне, поставте **ліміт кредитів** (наприклад, 5 000–10 000): так випадковий запуск не витратить більше, ніж ви дозволили.
   - Без дозволу на голоси ID голосу береться вручну: на сайті Voices → My Voices → «⋯» біля голосу → **Copy voice ID**, далі `node tools/voice/sample.mjs --voices ID`.
3. Скопіюйте ключ і в корені проєкту (поруч із `package.json`) створіть файл **`.env.local`** з одним рядком:

   ```
   ELEVENLABS_API_KEY=сюди_ваш_ключ
   ```

   Файл не потрапляє на GitHub (він у `.gitignore`). **Не надсилайте ключ у чат.**

## 3. Голос

Є три шляхи — можна поєднувати:

- **Готовий голос.** У ElevenLabs: Voices → Library — фільтр за мовою (Polish, Ukrainian, English), послухайте й натисніть «Add to my voices». Добре підходять теплі жіночі або спокійні чоловічі голоси «для дітей / оповідача».
- **Ваш власний голос (клон).** Voices → Add a new voice → **Instant Voice Clone**: завантажте 1–3 хвилини чистого запису свого голосу (тиха кімната, без музики, рівно й дружньо). Один клон говорить усіма трьома мовами. Клонувати можна лише свій голос (або людини, яка дала згоду).
- **Різні голоси для мов** — теж можна: окремий голос для pl, uk, en.

Подивитися свої голоси та їхні `voice_id` (кредитів не витрачає):

```bash
node tools/voice/voices.mjs
```

## 4. Проба на слух

```bash
node tools/voice/sample.mjs --dry
node tools/voice/sample.mjs
```

- `--dry` лише показує, скільки символів (кредитів) піде.
- Без параметрів скрипт сам бере ваш клон (якщо є) і два готові жіночі голоси, для трьох мов, модель `eleven_v4`.
- Конкретні голоси: `--voices ID1,ID2`; лише одна мова: `--langs uk`; порівняти моделі: `--models eleven_v4,eleven_multilingual_v2`.

Потім відкрийте у браузері файл **`voice-samples/index.html`** (подвійний клік) і послухайте:

- **«▶ ціле»** — речення одним файлом (так звучатимуть незмінні репліки);
- **«▶ зі шматків»** — те саме речення, складене з окремих файлів (так звучатимуть фрази з числами); повзунком угорі можна змінити паузу між шматками;
- **«▶ лічба по одному»** — числа окремо (особливо 13 / 30, 14 / 40).

Скажіть мені: який голос (для кожної мови), яка модель, чи не надто швидко чи повільно, і чи чути стики у «шматках».
