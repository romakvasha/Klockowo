# Реалістичний голос (ElevenLabs) — інструкція для власника

Голос генеруємо **один раз на вашому комп'ютері** і зберігаємо як mp3-файли в проєкті (`public/audio/<мова>/`). Сайт лише програє готові файли: ключ ElevenLabs і запити до сервісу на сайт не потрапляють, офлайн-режим працює.

**Як звучить у грі.** Кожне речення — окремий запис, зроблений **цілим реченням** (без склеювання зі шматків). Висловлювання (те, що Kubik каже за раз) звучить записом, лише якщо записано **всі** його речення; інакше все висловлювання каже голос браузера. Два голоси в одній фразі не змішуються.

## 1. Акаунт і кредити

- Безкоштовний тариф — 10 000 кредитів на місяць; Starter — 30 000 (перший місяць часто зі знижкою, далі продовжується автоматично за звичайною ціною; якщо не потрібно — скасуйте продовження в налаштуваннях підписки). Ціни: https://elevenlabs.io/pricing.
- Записати **все**, що гра каже польською, — ≈ 274 000 символів (тисячі різних фраз із числами). Тому записуємо найчутніше:

  | бюджет (символів) | звучить записом (того, що чує дитина) |
  |---|---|
  | 6 500 | ≈ 67 % (усі числа, 91 % екранів, 45 % реплік в іграх) |
  | 30 000 | ≈ 85 % (усі числа, 94 % екранів, 75 % ігор) |
  | 36 000 | ≈ 87 % |

- Кредитів іде **не більше**, ніж символів: `eleven_v4` на тарифі Starter брав ≈ 0,4 кредиту за символ (скільки саме — пише скрипт під час запису).
- **Зараз записано (польська):** 2 963 речення ≈ 96 % (жовтень 2026, ≈ 36,7 тис. кредитів). 99 % — ще ≈ 90 000 символів (≈ 36 000 кредитів).

## 2. Ключ API

1. На сайті ElevenLabs: аватар → **API Keys** → **Create API Key**.
2. Дозволи: обов'язковий лише **Text to Speech**. Поставте **ліміт кредитів** на ключ (щоб випадковий запуск не витратив більше, ніж ви дозволили); якщо запис зупинився з помилкою про кредити — підніміть ліміт, і повторний запуск продовжить із того самого місця.
   - Без дозволу на голоси ID голосу береться вручну: Voices → My Voices → «⋯» → **Copy voice ID**.
3. У корені проєкту (поруч із `package.json`) файл **`.env.local`** з одним рядком:

   ```
   ELEVENLABS_API_KEY=сюди_ваш_ключ
   ```

   Файл не потрапляє на GitHub (він у `.gitignore`). **Не надсилайте ключ у чат.**

## 3. Голос і проба на слух

- Голос і модель — у `tools/voice/config.json` (`voices.pl`, `model`). Зараз для всіх мов: **Sarah — Mature, Reassuring, Confident**, модель `eleven_v4`, швидкість 0,95.
- Для української Sarah іноді вимовляє «и» по-російськи («адин»): перед записом української підберемо **голос носія мови** (Voices → Library → фільтр Ukrainian) і перевіримо пробою.
- Проба кількох голосів (≈ 300 символів на мову для кожного голосу):

  ```bash
  node tools/voice/sample.mjs --langs uk --voices ID1,ID2
  ```

  Потім відкрийте `voice-samples/index.html` (подвійний клік) і послухайте.

## 4. Запис голосу для гри

```bash
node tools/voice/generate.mjs --lang pl --budget 30000 --dry
node tools/voice/generate.mjs --lang pl --budget 30000
```

- `--dry` — лише план: скільки речень, символів і яка частка гри звучатиме записом (кредитів не витрачає, ключ не потрібен).
- Без `--dry` скрипт питає «так» і записує. Записане зберігається після кожного файла: перерваний запуск (мережа, кредити) **продовжується з того самого місця**, а вже записане вдруге не оплачується. Наступного місяця той самий рядок із більшим `--budget` допише ще.
- Речення звучить погано (не той наголос, шум)? Запишіть наново лише його:

  ```bash
  node tools/voice/generate.mjs --lang pl --redo "Ile jest jabłek?" --budget 0
  ```

- `--prune` прибирає записи фраз, яких гра вже не каже (після зміни текстів).
- Після запису файли треба закомітити (разом із `public/audio/pl/manifest.json`) — так вони потраплять на сайт.

## 5. Перевірка в грі

- `npm run dev` → гра говорить записом там, де він є. Послухайте особливо числа 11–19 і десятки (13/30, 14/40).
- **Strefa rodzica → Ustawienia → «Nagrany głos»**: вимикач записаного голосу (видно, лише коли є записи для мови гри). Вимкнено — усе каже голос браузера.
- «Tempo mowy» і повзунок «Mowa» діють і на записи (звичайний темп 0,9 — запис як є).
- Записи кешуються для офлайну разом із грою.
