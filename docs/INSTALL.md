# Klockowo — як запустити на телефоні чи планшеті

Сайт працює **без інтернету**: після першого відкриття все (код, малюнки, шрифти) зберігається в пам'яті пристрою. Прогрес дитини лишається **лише на цьому пристрої** (у браузері) — тому корисна «Kopia zapasowa» у Strefa rodzica.

## Як відкрити вдома на ПК (перевірка)

```bash
npm install
npm run dev
```

Адреса: http://localhost:5173. Для телефона в тій самій Wi-Fi: `npm run dev -- --host` і відкрити адресу з IP комп'ютера (наприклад `http://192.168.0.12:5173`). **Увага:** так працює лише гра — режим «встановити на екран» й офлайн **не вмикаються**, бо браузери дозволяють їх лише на захищених адресах (`https://…`) і на `localhost`.

Збірка, як вона буде в телефоні: `npm run build`, потім `npm run preview` (http://localhost:4173).

## Як поставити на телефон як застосунок (офлайн)

Потрібна адреса з `https://`. Є два способи — **публікація потребує вашої згоди**, тож без вашої команди я її не роблю:

1. **GitHub Pages** (безкоштовно): у репозиторії https://github.com/romakvasha/Klockowo → Settings → Pages → Build and deployment: **GitHub Actions**. Скажіть мені «опублікуй» — я додам файл публікації, і сайт з'явиться за адресою на кшталт `https://romakvasha.github.io/Klockowo/`.
2. **Netlify Drop** (безкоштовно, без акаунта GitHub): `npm run build`, потім перетягнути теку `dist` на https://app.netlify.com/drop — отримаєте адресу `https://….netlify.app`.

Після публікації на телефоні:

- **Android (Chrome):** відкрити адресу → меню ⋮ → **«Установити застосунок»** (або «Додати на головний екран»). Іконка «K» з кубиків з'явиться серед застосунків.
- **iPhone / iPad (Safari):** відкрити адресу → кнопка «Поділитися» → **«На екран “Додому”»**.

Перший запуск має бути **з інтернетом** (щоб усе завантажилось). Далі працює без нього. Новий реліз підтягнеться сам при наступному відкритті з інтернетом.

## Мова гри

На екрані Start ліворуч угорі — кнопки **PL**, **UA** і **EN** (польська, українська, англійська). Дотик перемикає мову гри: усі написи й голос, а також мову зони для дорослих. Обрана мова запам'ятовується на пристрої. За замовчуванням — польська.

## Голос

Гра розмовляє мовою гри через голос самого пристрою. Якщо в браузері нема голосу обраної мови, з'явиться повідомлення для дорослого; голос можна додати в системі (Android: «Налаштування → Система → Мови → Синтез мовлення» → Google, потрібна мова; iOS: «Налаштування → Універсальний доступ → Промовлений вміст → Голоси» → Polski / Українська (Lesya) / English; Windows: «Параметри → Час і мова → Мова» → додати мову з функцією «Перетворення тексту на мовлення»). Вибрати голос — у **Strefa rodzica → Ustawienia → Głos**.

## Strefa rodzica (для дорослих)

Утримуйте шестерню на мапі 3 секунди → відповісти на приклад на множення («siedem razy osiem»). Там: прогрес, труднощі, налаштування, профілі й **резервна копія** (експорт у файл — зробіть його перед очищенням даних браузера чи заміною телефона).

## Якщо щось пішло не так

- Гра «застрягла» на старій версії → закрити й відкрити застосунок двічі з інтернетом (оновлення підтягується при запуску).
- Дані зникли → браузер міг очистити сховище (приватний режим, «очистити дані сайту»). Відновлення — імпорт файла копії в Strefa rodzica.
