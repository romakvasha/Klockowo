# Klockowo — новий дизайн (v2): 3D-світ іграшкових цеглинок

Основа — 25 фото власника (`design/v2/photos/`) і макет `design/v2/mockup.html`. **Логіка гри не змінюється:** ті самі екрани, кнопки, порядок, тексти й голос; міняється лише вигляд. Цей файл переважає `design/` (старий експорт) у всьому, що стосується вигляду; поведінка й тексти — як і раніше за `docs/BRIEF.md`.

## 1. Стиль

- 3D-рендер «як мультфільм»: м'яке світло, насичені основні кольори, глянцевий пластик, пухнаста шерсть, великі очі.
- Світ із **загальних** іграшкових цеглинок із круглими пупирцями — без логотипів і назв брендів.
- Запити для генератора: `tools/art/assets.mjs` (спільний стиль `STYLE` + опис кожної картинки).

## 2. Персонажі

| хто | порода / вигляд | нашийник і жетон |
|---|---|---|
| **Kubik** (провідник) | бігль з фото (рудо-білий, довгі вуха) | синій нашийник, **жовта кругла цеглинка-підвіска** |
| Łatka (W1–W2) | джек-рассел, біла з рудими плямами | зелений, зелена цеглинка |
| Pufka (W3) | пухнастий самоїд | блакитний, блакитна цеглинка |
| Tofik (W4–W5) | пшеничний скотч-тер'єр, «блоковий» силует | кораловий, коралова цеглинка; без пожежного спорядження |
| Iskra (W7) | рудо-білий коргі | фіолетовий, фіолетова цеглинка |
| 8 цуценят «Twój piesek» | PON, ньюфаундленд, пудель, хорт, папійон, ші-тцу, шарпей, смугаста акіта (як у голосових описах) | простий нашийник **без жетона** |

- **Жетони як у «Psi Patrol» прибрано:** замість срібної підвіски-лапки — маленька кругла іграшкова цеглинка з одним пупирцем, кольору нашийника. Без емблем і значків.
- **Далматинця й вівчарок у грі немає** (BRIEF: не схоже на «Psi Patrol»). Цуценята з фото, що не входять у гру (далматинець, спанієль, лабрадор тощо), не використовуються.
- Однаковість персонажа: кожну картинку генеруємо зі зразком (`refs`) — вирізаним Kubikом з фото.
- Kubik говорить: 3 кадри рота (a / e / o) тієї самої пози змінюються, поки звучить голос (як зараз у SVG).

## 3. Розкладка без накладань (головна вимога)

Жоден елемент не лежить на іншому, крім фону. Кожен екран — сітка з окремими зонами:

```
Альбомна (ПК, планшет, телефон боком)        Книжкова (телефон)
┌──────────────── HUD ────────────────┐      ┌──────── HUD ────────┐
│ Mapa · кісточки · Posłuchaj · Pomoc │      ├─────────────────────┤
├────────────┬────────────────────────┤      │ Kubik │ хмаринка     │  ← зона провідника (≤ 22 % висоти)
│ Kubik      │  дошка завдання        │      ├─────────────────────┤
│ + хмаринка │  (предмети / сцена)    │      │ дошка завдання      │
│ (≤ 26 %)   │                        │      │                     │
├────────────┴────────────────────────┤      ├─────────────────────┤
│        відповіді / кнопки           │      │ відповіді / кнопки  │
└─────────────────────────────────────┘      └─────────────────────┘
```

- Зони — CSS Grid (`grid-template-areas`), розміри від екрана; між зонами щонайменше 16 px.
- Хмаринка з текстом — усередині зони Kubika, ніколи не над дошкою.
- Текст ніколи не стоїть просто на фото: лише на білій напівпрозорій картці.
- Фон: на меню — фото світу без розмиття; у грі — розмите (щоб предмети читались); затемнення країв для контрасту.
- Цілі дотику ≥ 64 px (телефон ≥ 80), як і зараз; `prefers-reduced-motion` і «Mniej animacji» діють.

## 4. Інтерфейс (малюється кодом, не картинками)

- Кнопки, плитки-відповіді, картки цифр — **глянцеві цеглинки**: градієнт, блік зверху, темніший низ, 1–2 пупирці; натиск — цеглинка «вдавлюється».
- Кольори: червоний `#E8352F`, жовтий `#FFCF1F`, синій `#1F7FE0`, зелений `#3FAE35`, помаранчевий `#FF8A1F`, фіолетовий `#8B4FE0`; небо `#3D9CF0`; текст `#2B2A4A`.
- Шрифти без змін: Fredoka (заголовки, цифри), Nunito (текст), Andika (букви для читання).
- Іконки (дім, динамік, підказка, налаштування…) — SVG у тому самому глянцевому стилі.
- Логотип «Klockowo» — літери на кольорових цеглинках.

## 5. Картинки: як робимо

1. `tools/art/generate.mjs` (етап D1) бере `tools/art/assets.mjs`, надсилає запит і зразки обраному сервісу генерації зображень (ключ лише в `.env.local`), кладе результат у `design/v2/gen/`.
2. Фон вирізається (`rembg`, модель isnet-general-use), краї обрізаються; персонажі — до 768 px заввишки, фони — 1920×1080; формат WebP.
3. Галерея `design/v2/gallery.html`: власник переглядає й позначає, що перегенерувати.
4. У гру — `src/assets/v2/…`; картинки світу підвантажуються, коли дитина входить у світ, і кешуються для офлайну (як голос).
