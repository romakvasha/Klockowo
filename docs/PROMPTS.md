# Промпти для Claude Code

Відкривайте Claude Code у папці `klockowo`. **Кожен етап — у новій сесії.**

## Перша сесія
```
Привіт! Це проєкт «Klockowo» — сайт-гра з математики польською для моєї дитини (5–6 років).
Прочитай CLAUDE.md і docs/PLAN.md. Дизайн із Claude Design я поклав у папку design/.
Виконай етап M0 за правилами з CLAUDE.md, потім зупинись і скажи, що перевірити й що далі.
```

## Кожна наступна сесія
```
Продовжуємо Klockowo. Виконай наступний невиконаний етап із docs/PLAN.md за правилами CLAUDE.md.
```

## Якщо попередню сесію обірвав ліміт
```
Продовжуємо Klockowo. Попередня сесія обірвалась посеред етапу. Подивись git status, останні коміти й «Журнал» у docs/PLAN.md і заверши незакінчений етап.
```

## Знайшли помилку
```
Новий етап не починай. Виправ помилку: <екран або гра> — <що робили> — <що сталося> — <що мало статися>. Потім build, test, коміт і запис у «Журнал».
```

## Оновили дизайн
```
Я оновив файли в design/. Онови design/INDEX.md і скажи, які вже зроблені екрани чи компоненти треба змінити. Нічого не змінюй без мого підтвердження.
```

## Відгук дитини
```
Дитина пограла в <світ або гру>. Що було: <сподобалось / нудно / складно / не зрозуміла, що робити>. Запропонуй 2–3 невеликі зміни, нічого не змінюй до мого вибору.
```

## Як берегти ліміт
- Один етап — одна нова сесія: коротка розмова витрачає менше.
- Не вмикайте ultracode і не просіть «workflow» чи «агентів»: кілька агентів витрачають ліміт у рази швидше.
- Для звичайних етапів вистачить Sonnet; Opus вмикайте для складних (M8 — рушій, M18 — таблиця 100) або якщо Sonnet не впорався.
- Не вставляйте в чат великі файли й архіви — кладіть їх у папку `design/`.
- Якщо сесія обірвалась — нічого не втрачено: прогрес у git і в «Журналі» `docs/PLAN.md`.
